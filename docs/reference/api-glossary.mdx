# API glossary

This is the full public surface of Dendrux: everything you import in normal use. Each entry links to the page that explains it in depth. If a symbol is not listed here, treat it as internal and subject to change.

## Core

| Symbol | Import | What it is |
| --- | --- | --- |
| `Agent` | `from dendrux import Agent` | The agent: definition + runtime facade. See [Agent](/docs/reference/agent). |
| `tool` | `from dendrux import tool` | Decorator that turns an async function into a tool. |
| `Budget` | `from dendrux import Budget` | Per-run token and dollar limits with optional pause or cancel, counting delegated children. See [Budget](/docs/architecture/budget). |
| `heartbeat` / `aheartbeat` | `from dendrux import heartbeat, aheartbeat` | Call from inside a long-running tool to refresh persisted progress and reduce the risk of the stale sweep reaping the run (best-effort; no-op outside a persisted run). See [State persistence](/docs/architecture/state-persistence#long-running-tools-and-the-stale-sweep). |
| `run` | `from dendrux import run` | Low-level functional runner behind `Agent.run` (advanced use). |
| `sweep` | `from dendrux import sweep` | One-shot reconciliation of stale/abandoned runs (you schedule it). |
| `Limits` | `from dendrux import Limits` | Size caps for `Agent(limits=...)`: `max_tool_result_bytes`, `max_input_bytes`, `max_metadata_bytes`, `max_notes_per_run`. See [Agent](/docs/reference/agent#limits). |
| `UNSCOPED` | `from dendrux import UNSCOPED` | The "every tenant" scope for reads and run-control writes; `None` means untenanted only. See [Multi-tenancy](/docs/architecture/multi-tenancy). |

## Guardrails

| Symbol | Import | What it is |
| --- | --- | --- |
| `PII` | `from dendrux.guardrails import PII` | Redact/block/warn on PII (regex or Presidio). `restore="all"` or `"allowlisted"` chooses which tools get real values back. See [Guardrails](/docs/architecture/guardrails) and [PII restore](/docs/architecture/pii-restore). |
| `SecretDetection` | `from dendrux.guardrails import SecretDetection` | Block on leaked secrets (AWS keys, tokens, PEM). |
| `PromptInjection` | `from dendrux.guardrails import PromptInjection` | Regex injection guard (you supply patterns). See [Patterns](/docs/recipes/prompt-injection-patterns). |
| `Pattern` | `from dendrux.guardrails import Pattern` | A named regex `Pattern(name, regex)`. |
| `Guardrail` | `from dendrux.guardrails import Guardrail` | Protocol for custom guardrails (`async scan(text)`). |
| `Finding` | `from dendrux.guardrails import Finding` | One detection: entity type, span, score, text (in process only; events and errors carry the kind, count and location, never the text). |
| `ImageGuardrail` / `ImageScanInput` | `from dendrux.guardrails import ImageGuardrail, ImageScanInput` | Opt-in protocol for guardrails that scan images (`async scan_image(image)`). See [Images](/docs/recipes/images#guardrails). |

## Images

| Symbol | Import | What it is |
| --- | --- | --- |
| `Image` | `from dendrux.media import Image` (also importable from `dendrux`) | An image input: `from_bytes`, `from_path`, `from_base64`, `from_url`. Accepted in `user_input`, `ChatMessage.user`, `ToolOutput` and `ToolResult.images`. |
| `ToolOutput` | `from dendrux.media import ToolOutput` (also importable from `dendrux`) | What a server `@tool` returns to attach images: `ToolOutput(result, images=[...])`. |
| `ImageRef` / `ImagePart` / `TextPart` | `from dendrux import ImageRef, ImagePart, TextPart` | A stored image's descriptor, and the ordered parts of a multimodal `Message.parts`. |
| `ImagePolicy` / `ImageDropPolicy` / `UrlPolicy` | `from dendrux.media import ImagePolicy, ImageDropPolicy, UrlPolicy` | `Agent(images=...)`: caps, non-vision behaviour, the drop-old-images window, URL fetching and the ingest hook. |
| `BlobStore` / `BlobKey` / `InMemoryBlobStore` | `from dendrux.media import BlobStore, BlobKey, InMemoryBlobStore` | The byte-storage protocol for `Agent(blob_store=...)`. See [S3 recipe](/docs/recipes/images-s3). |
| `agent.blobs` | `Agent.blobs` | `read`, `info`, `references`, `purge` and `collect_garbage` for stored images. |

The guide is [Images](/docs/recipes/images).

## Persistence and reads

| Symbol | Import | What it is |
| --- | --- | --- |
| `RunStore` | `from dendrux.store import RunStore` | Read-only facade over the six tables. See [RunStore](/docs/reference/run-store). |
| `PendingPause` / `PendingToolCall` | `from dendrux.store import PendingPause, PendingToolCall` | What a paused run waits on, from `RunStore.get_pending`. See [Build your own read routes](/docs/recipes/build-your-own-read-routes). |
| `Follow` / `FollowEnd` / `FollowHeartbeat` / `FollowCapacityError` / `EventFeed` | `from dendrux.store import ...` | The hardened live feed behind `RunStore.follow`. |
| `redact_event` | `from dendrux.store import redact_event` | Conservative standalone event projection; use `RunStore.get_event_view` for verified active approval arguments. |
| `tool_pool_stats` | `from dendrux import tool_pool_stats` | Process-wide tool threads, queued calls and timed-out calls still running. |

`RunStore` read methods return these record types (all from `dendrux.store`): `RunSummary`, `RunDetail`, `StoredEvent`, `LLMCall`, `ToolInvocation`, `TraceEntry`, `PausePair`, plus `RunSubtree`, `SubtreeNode`, `RunUsage` (from `get_subtree`) and `RunNote` (from `get_notes`). Fields are documented on the [RunStore](/docs/reference/run-store) page.

## Tool sources

| Symbol | Import | What it is |
| --- | --- | --- |
| `MCPSource` | `from dendrux.mcp import MCPSource` | Immutable HTTP or stdio source configuration. See [MCP](/docs/architecture/mcp). |
| `MCPRuntime` | `from dendrux.mcp import MCPRuntime` | Process-wide managed owner of MCP connections: tenancy, capacity, circuit breaking, telemetry. Recommended for production. |
| `MCPConnection` | `runtime.bind(...)` / `await runtime.rebind(...)` | Lazy handle for one `(tenant_key, connection_key)` identity; `connection.tools()` creates agent views, `await connection.discover()` returns the server's catalog without an Agent. |
| `MCPToolNotFoundError` | `from dendrux.mcp import MCPToolNotFoundError` | Raised by `await connection.call_tool(name, arguments)` for a tool the server does not list. `call_tool` runs a server tool directly and bypasses Agent governance; see [MCP](/docs/architecture/mcp#calling-a-tool-directly). |
| `MCPDiscovery` | `await connection.discover()` | Server name, version, protocol version, instructions, and the raw `MCPToolInfo` catalog of one connection. |
| `MCPToolView` | `connection.tools(...)` | Namespace and tool policy one agent consumes via `tool_sources=`. |
| `MCPCredentialProvider` | `from dendrux.mcp import MCPCredentialProvider` | Async protocol returning per-connect authentication (headers or env); resolved lazily, never persisted. |
| `MCPRuntimeObserver` | `from dendrux.mcp import MCPRuntimeObserver` | Sync callback protocol receiving typed runtime lifecycle events; pair with `runtime.snapshot()`. |
| `MCPHost` | `from dendrux.mcp import MCPHost` | Application-owned connections shared across a few agents, without tenancy or capacity; prefer `MCPRuntime` in services. |
| `MCPServer` | `from dendrux.mcp import MCPServer` | Backward-compatible source facade; prefer `MCPSource` in new code. |

## Errors

Run-control, skill-continuity, schema, and context-length exceptions live in `dendrux.errors`; common ones are re-exported from `dendrux`. MCP exceptions live in `dendrux.mcp`, RunStore read errors in `dendrux.store`, and several validation/idempotency exceptions are exported from `dendrux`. Full table with when-raised and suggested HTTP mappings on the [Errors](/docs/reference/errors) page: `RunNotFoundError`, `RunNotPausedError`, `PauseStatusMismatchError`, `RunAlreadyClaimedError`, `RunAlreadyTerminalError`, `InvalidToolResultError`, `PersistenceNotConfiguredError`, `SchemaNotInitializedError`, `SchemaOutOfDateError`, `ContextLengthExceededError`. Plus `RunAlreadyActiveError`, `IdempotencyConflictError`, `StructuredOutputValidationError`, `DelegationDepthExceededError` from `dendrux`. New in 0.5.0, also from `dendrux`: `ProviderError` and its subclasses (`ProviderAuthError`, `ProviderRateLimitError`, `ProviderTimeoutError`, `ProviderUnavailableError`, `ProviderStreamIncompleteError`, `ModelRefusalError`, `ContentFilteredError`), `BudgetConfigurationError`, `TenantScopeRequiredError`, `GovernanceMismatchError` and `NoteLimitExceededError`.
